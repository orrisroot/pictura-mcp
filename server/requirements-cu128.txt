# CUDA 12.8 build for pictura-mcp
#
# For machines whose NVIDIA driver supports up to CUDA 12.8 (e.g. 570.x
# drivers). The default PyPI torch wheels (torch 2.14 = cu130 build) require a
# CUDA-13-capable driver (>=580) and fail there with
# "CUDA driver version is insufficient" / "no kernel image" errors.
#
# cu128 wheels exist up to torch 2.11.x; all other deps in requirements.txt
# (diffusers / transformers / accelerate / ultralytics) only need torch>=2.6,
# so 2.11.0 satisfies them.
#
# Install:
#   python3 -m venv .venv
#   # 1) torch family from the cu128 index first, ...
#   ./.venv/bin/pip install "torch==2.11.0" "torchvision" \
#       --index-url https://download.pytorch.org/whl/cu128
#   # 2) ... then everything else from PyPI (keeps the 2.11.0+cu128 build).
#   ./.venv/bin/pip install -r server/requirements.txt
torch==2.11.0+cu128
torchvision

# Volta (V100 / compute capability 7.0) needs torch <=2.7.1 from the cu126
# index (newer builds dropped the sm_70 kernels; generation fails with
# "CUDA error: no kernel image is available"):
#   ./.venv/bin/pip install "torch==2.7.1" "torchvision==0.22.1" "torchaudio" \
#       --index-url https://download.pytorch.org/whl/cu126
#   ./.venv/bin/pip install -r server/requirements.txt
